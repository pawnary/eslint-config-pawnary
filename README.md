# ESLint and Prettier shared configurations

The goal of this repository is to provide [ESLint](https://eslint.org/) and
[Prettier](https://prettier.io/) shared configurations for TypeScript and React
packages.

## Available configurations

- [prettier-config](packages/prettier-config)
- [eslint-config-prettier](packages/eslint-config-prettier)
- [eslint-config-typescript](packages/eslint-config-typescript)
